Providers and policies

Compliance checklist

  • EU: Impressum complete (ECG § 5), Datenschutzerklärung (DSGVO Art 13), AGB with Widerrufsbelehrung and Muster-Widerrufsformular (FAGG), price incl. VAT and shipping shown before checkout (PAngV/PrAG), ODR link, button text "Buy" is unambiguous (§ 8 FAGG "zahlungspflichtig bestellen" is handled by Stripe's checkout button).
  • EU tax: originals 13 % / prints 20 % in Austria, or Kleinunternehmer up to 55.000 EUR turnover (2025 rules, check current threshold). Over 10.000 EUR EU distance sales per year: register for OSS in FinanzOnline.
  • EU accessibility: European Accessibility Act applies to e-commerce since 28.06.2025; Accessibility statement is generated.
  • US: no sales tax nexus as a foreign seller with low volume; state economic-nexus thresholds start at 100.000 USD per state, revisit if you approach that. CCPA/CPRA notice generated (you are far below the applicability thresholds, but the notice costs nothing). Customs: HTS 9701 artworks duty-free; state it.
  • Both: Stripe Tax can compute VAT/sales tax automatically once turned on in Stripe; Stripe also stores card data so you never touch it (PCI).
  • Before first sale: register the Gewerbe (Kunsthandel) or confirm the artist exemption with WKO, add the site to your Instagram bio, and put og.jpg into img/.

Publish

Direct publishing (phone or laptop)

One-time setup: create a free GitHub account and an empty repository, upload this folder into it, then in Netlify choose "Add new site → Import an existing project → GitHub" and pick the repository. From then on, every "Publish to site" here writes your photos and changes into GitHub and Netlify rebuilds the live site within about a minute. The token stays in this browser only.

Create it at github.com → Settings → Developer settings → Personal access tokens → Fine-grained → Only select repositories → Repository permissions → Contents: Read and write. Copy it here once.

Manual fallback

  1. Click "Download site.json + works.json" (top right). Two files land in your Downloads folder.
  2. Move both into the site folder, replacing the old ones. Move any downloaded photos into the img/ folder.
  3. Open your Netlify site, Deploys, and drag the whole site folder onto the page. Live in about a minute.

This desk stores nothing on a server. Everything lives in the two JSON files and the img/ folder; back them up once in a while (a copy of the folder is a full backup of the shop).

Working locally: opening admin.html directly from disk cannot read the JSON files (browser rule), so use "Load files…" and pick site.json and works.json together. On the live site (yoursite.netlify.app/admin.html) they load automatically. The preview on the right always reflects your unsaved edits.

Drag the frame to move it, drag a corner to resize. Crop to the painting itself when the site adds frame and mat; keep carpet and frame in the photo when "no mat" is set.
